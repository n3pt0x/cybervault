# 📤 Dumping

- [ESP Firmware Toolbox](https://github.com/wilco375/ESP-Firmware-Toolbox) - Collection for dumping, reverse and patching ESP32 firmware.

## ⚡ Flash / Dump

- [flashrom](https://github.com/flashrom/flashrom) - Decteting, reading, writing, verifying, erasing flash chips.
- [esptool](https://github.com/espressif/esptool.git)
- [binwalk](https://binwalk.app/) - Find / Extract structure (files, FS, streams, binary, bootloader & much more).

### GUI

- [IMSProg](https://github.com/bigbigmdm/IMSProg) - CH341A-based programmers (I2C, SPI, EEPROM/Flash).
- [AsProgrammer](https://asprogrammer.com/) - Flash, Backup & Restore Memory Chips with Ease (Windows).
